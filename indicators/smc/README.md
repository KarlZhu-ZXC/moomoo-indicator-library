# Smart Money Concepts (`SMC_*`)

Three stackable moomoo Python overlay indicators adapted from the open-source **Smart Money Concepts (SMC) [LuxAlgo]** Pine Script.

| Indicator | Purpose | Plot budget |
|---|---|---:|
| [`SMC_STR.py`](SMC_STR.py) | Structure, BOS/CHoCH, swing points, EQH/EQL, Strong/Weak | 28 / 50 |
| [`SMC_OB.py`](SMC_OB.py) | Internal and swing Order Blocks | 50 / 50 |
| [`SMC_IMB.py`](SMC_IMB.py) | FVG and Premium/Equilibrium/Discount | 46 / 50 |

Create each file as a separate Python overlay indicator in moomoo Desktop, then stack the modules on the same chart.

See the [compatibility matrix](../../docs/smc/COMPATIBILITY.md), [v3.2 notes](../../docs/smc/README_V3_2_CN.md), and [Chinese handbook](../../docs/smc/Smart_Money_Concepts_实战手册_CN.md).
